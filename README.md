# ISL Interpretation and Chatbot System

A comprehensive accessibility solution developed for the Smart India Hackathon (SIH) 2024. This project bridges the communication gap by providing real-time Indian Sign Language (ISL) interpretation and an integrated AI chatbot.

## Core Modules

- **`ISL/`**: The computer vision pipeline. It utilizes advanced pose estimation and hand-tracking (e.g., MediaPipe) combined with sequence models (LSTMs/Transformers) to translate live Indian Sign Language gestures into text.
- **`chatbot/`**: A conversational AI interface that takes the translated text and allows the user to interact with digital services, ask questions, or synthesize speech output.
- **`WF/`**: Contains the wireframes and workflow definitions for the integrated application UI.

## Impact

By translating ISL in real-time, this system empowers the deaf and hard-of-hearing community to interact seamlessly with both digital assistants and individuals who do not know sign language.
